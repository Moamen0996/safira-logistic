# safira-logistic
"Build a shipping management web app connecting three user types: merchants, delivery agents, and admin.
Merchant login via unique code. Merchant dashboard: add orders (customer name, phone, governorate, address, waybill number, amount, payment method: InstaPay / digital wallet / cash), view their own orders and status, view their financial dues.
Delivery agent dashboard: view orders assigned to them based on their governorate, update each order status once only (delivered, rejected, or returned), view their earnings.
Admin dashboard: full view of all orders and details, assign orders to agents by governorate, track all agents, view all merchant and agent accounts, profit and loss calculation.
Real-time status updates visible to merchants and admin when agent updates an order."
